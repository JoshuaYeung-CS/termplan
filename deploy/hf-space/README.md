# Termplan

Paste or upload your course syllabi. Termplan reads them with NVIDIA Nemotron on Nebius Token
Factory, checks every deadline against the exact syllabus sentence it came from, flags clashes and
crunch weeks, and gives you a calendar file and a week-by-week study plan.

Source code and setup: see the GitHub repository linked in the project description.
